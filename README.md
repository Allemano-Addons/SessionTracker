# Allemano Ledger

(Formerly Session Tracker.) Your gold, XP and time in one place, for WoW Forever.

- `/ledger` opens the Ledger window: **Now** (this session, income by source, graph), **History** (gold per day,
  finished sessions and instance runs), **Lifetime** (totals since install) and **Alts** (soon).
- `/session` (or `/sesh`) shows/hides the small session window with time, gold, gold per hour, XP and time to level.
  `/ledger reset` starts a new session.
- Gold is tracked by source (loot, vendor, quests, auction house, mail, trades) and expenses (repairs, vendor, ...).
  Gold moved between your own characters is not counted as income.
- When you leave a dungeon or raid, a summary of the run pops up.
- `/ledger levels`: how long every level took (/played time). `/ledger settings`: look and behaviour.
- Something not working? `/ledger errors` lists recent errors (WoW Forever hides Lua errors).
